# 拉绳揭开的书斋舞台

书斋背景来自 `toy-wind-scene-v2`，按其 `CODEX_TASK.md`、接入说明与分层说明迁入正式博客。交接目录保持原样。

## 范围

- 闲暇娱乐栏目提前准备包含竹枝、松梅及三处投影的完整静止首帧，开始拉动时就从纸页后方显露舞台，同时按需创建动态环境。普通栏目不请求环境素材。
- 延续当前拉绳、卷页、手机纸幕、迟滞与返回文章行为。舞台与绳子、文章纸面分层。
- 仅接入书斋环境；未引入评审导航、七张占位 Cover、虚构作品、视频或项目网址。
- 宽幅场景整体保持 1586×992 比例，以 cover 方式铺满视口。窄屏统一向窗侧取景；底图、植物和所有投影一起缩放和裁切，不独立变更任何一层的坐标。

## 实现

`src/components/LeisureStage.tsx` 提前加载隐藏的完整静止首帧；`src/lib/stage/scene.ts` 在开始预览时动态导入。静止首帧由同一生产渲染器在 time=0、风力=1.4 时合成，只包含场景本身，不含页面 DOM、绳子或按钮。动态画布从相同姿态开始并完整覆盖首帧，不重复叠加静态植物。页面仅保留“返回文章”，不提供暂停环境动画操作。源码、风场、配置和渲染器均为严格 TypeScript，不依赖交接包的全局脚本，不增加运行依赖。

竹枝和松梅各使用 10×8 网格，根点固定。每帧只生成一次变形植物图，墙、地面和案几的投影复用该图，再绘制可见植物。风力使用原包的最大参数 1.4（原范围 0—1.4），不把该美术参数当作气象风级。投影是原包校准的二维仿射近似，并非三维光线追踪。

沿用六个运行素材，存放于 `src/assets/stage/`，通过静态导入获得内容哈希。默认底图 `room-base.webp` 仅减弱了中央固定叶影，仍包含原有静态植物、窗景和部分基础光影；不是完全拆净的底板。原图对照、独立旧阴影与 Cover 占位均未打包。

`room-still.webp` 是预载及失败降级使用的完整场景首帧，不替换运行时的 `room-base.webp`。导出步骤见 `output/playwright/generate-stage-still.js.txt`，生成参数和源文件校验记录见 `src/assets/stage/room-still.meta.json`。修改植物素材、位置、投影或风力后需同步重新导出，并对照静止首帧与真实 time=0 画布。

环境与交互 DOM 分开；背景 `pointer-events:none`，返回按钮保持真实 DOM、键盘焦点与网站颜色令牌。预览与回落期间，背景仍处于 inert 区域。

“返回文章”位于地毯前沿留白，以宋体小字和苔绿文字呈现，无白底面板；点击区域保留至少 44px 高度，悬停与键盘焦点用文字下划线提示。预览中关闭 Next.js 开发设置浮标，编译与运行错误仍按框架机制呈现。

## 生命周期与降级

- 绘制目标 30fps，渲染宽度最多 1440、DPR 最多 1.5；持续绘制耗时超过预算时先降至 1100，再降至 900。背景文字不进入 Canvas。
- 减少动态效果时呈现静态场景，继续响应系统设置变化。
- 离开视口、页面隐藏和可见原生模态框均停止循环。模态框关闭恢复原环境时钟；没有引入真实视频或自动播放。
- 返回时冻结当前背景，纸页在原进度轴关闭后移除场景，恢复页码、滚动与焦点。继续沿用原转场的页面隐藏/打印恢复文章行为。
- 松手确认进入时立即隐藏绳子和木头人，不等待回弹静止；未确认的回落保持可见，返回文章后重置并恢复拉绳。
- 加载失败保留静态底图和返回操作；底图也不可用时保留暖白背景。无 JavaScript 时完整文章栏目照常显示。
- 加载途中返回会中止图片初始化；卸载断开监听、ResizeObserver、IntersectionObserver、MutationObserver，取消 RAF 并释放画布缓冲。
