# Sachi Blog 关于我页面 UI 设计说明

本说明用于制作「请叫我木头人」博客的高保真 UI 稿件。新增页面对外名称统一为「关于我」，页面路径为 `/about/`。页面展示更完整的个人介绍、写作日历、兴趣与近况，以及可选的公开链接。

入口已确定为两个：首页现有头像、文章末尾署名区的「关于我 →」。首页继续保留「浏览目录」作为主要文字入口，目录页保持现有设计。

## 设计目标

读者进入页面后，应当依次了解作者是谁、为什么记录、写作如何持续发生，以及最近关注的事情。页面延续个人手记的阅读感，以文字和留白组织内容；写作日历是主要的可视化元素。

这次交付包含新增页面的桌面与移动设计、两个现有入口的局部修改，以及热点图的交互状态。稿件须能用于后续前端实现。

## 页面入口

### 首页头像

首页简介旁的现有头部头像整体成为链接，点击后在当前标签页进入 `/about/`。头像保留原有位置、比例和尺寸，首页的题签、签名、简介、桌面插画与「浏览目录」入口保持现有构图。

- 桌面现有头像容器约为 56 × 64px；手机沿用现有约 48px 宽的头像规格。
- 鼠标移入显示手形光标，并在头像附近显示简短提示「关于我」。提示不挤动简介，也不遮挡「浏览目录」。
- 键盘聚焦时显示清楚的苔绿色焦点轮廓，同时显示同一提示。
- 链接的可访问名称为「关于我」。触屏点击直接进入页面，不依赖悬停提示。
- 保留透明头像的完整轮廓，不增加圆形裁切、头像徽章或跳动动画。

首页不增加新的「关于我」文字入口。目录头像和站名仍按现有方式返回首页。

### 文章末尾署名区

在现有半身头像、作者名和简介组成的署名区中，于简介下方增加「关于我 →」。链接和简介左对齐，沿用现有低调文字链接样式。

- 字号 14px，宋体，与简介间距约 12—16px。
- 默认使用苔绿色或项目现有文字链接颜色，悬停时加深，箭头可按现有交互轻微右移。
- 点击区域高度至少 44px，手机同样可以方便点击。
- 点击后在当前标签页进入 `/about/`。
- 保留文章原有「返回目录」入口，署名区入口与它分别排版。

## 页面内容与阅读顺序

页面自然向下滚动。桌面首屏优先展示身份介绍与完整热点图，其他个人信息在下方继续展开。

| 顺序 | 区域 | 内容与职责 |
| --- | --- | --- |
| 1 | 页头 | 左侧「← 返回首页」，右侧小号站名，沿用现有共享页头；页头不放头像 |
| 2 | 身份与介绍 | 页面标题「关于我」、现有头部头像、作者名、原有签名与简介，以及一段扩展介绍 |
| 3 | 写作日历 | 年份、本年发布篇数、发文天数、热点图、统计口径与选中日期的文章 |
| 4 | 生活里的我 | 长期兴趣、生活习惯、在意的事情，以短段落或普通列表表达 |
| 5 | 最近在做 | 两到三条阶段性近况，附各自的更新时间 |
| 6 | 公开链接 | 可选的 GitHub、其他公开主页或联系方式，使用文字链接 |
| 7 | 页脚 | 沿用现有版权格式和低调样式 |

### 身份与介绍

标题「关于我」是页面唯一一级标题。作者名、签名、简介形成一个完整身份区，头部头像放在正文身份区内。

扩展介绍用于讲述写博客的原因、喜欢记录的内容与个人生活态度，正式内容约 150—250 字。稿件可先使用本说明后面的样例文案；职业、城市、学校、年龄、真实社交账号等信息不自行编造。

### 生活里的我与最近在做

桌面将这两个区域并排排列，手机依次纵向排列。两个区域通过标题和留白区分，不使用两个带阴影的卡片。

「生活里的我」包含两到三段简短内容。「最近在做」每条近况由一句正文和小号日期组成，不设置进度条、完成率或状态徽章。

### 公开链接

只展示已填写的链接，使用清楚的文字名称。没有公开链接时，整个区域收起，不留下空标题、空图标或待填写按钮。稿件中的演示账号、邮箱不得当作作者真实信息。

## 桌面布局

以 1440 × 900px 作为主要桌面画板，完整页面允许超过一屏。页头和页脚沿用现有外框，主体最大宽度为 960px，水平居中。

          关于我

          原有简介                   喜欢记录什么

          写作日历                              2026年

          一段学习笔记                       蘸豆！！ →

          ─────────────────────────────────────────

上图中的统计和文章为设计样例，完整数据见后文。

- 主体与页头之间约 48—64px。
- 「关于我」标题下方约 32px 后进入身份区。
- 身份区左右分栏，左侧约 320px，右侧占剩余空间，中间留出约 48—64px。
- 身份区与写作日历之间约 56—64px。
- 写作日历横跨主体宽度，前后以 1px 细线组织空间。
- 下半部分双栏间距约 64px，主要区域之间采用 48—64px 间距。
- 不为保持首屏而压小文字、缩小头像或压缩行距。低高度屏幕允许正常滚动。

## 写作日历的数据定义

第一版展示发文频率，统计口径统一为「当前公开文章的首次发布日期」。UI 保留「写作日历」标题、年度统计与年份，不常驻展示统计口径、数据截止日、图例说明或键盘操作提示。

| 项目 | 规则 |
| --- | --- |
| 当日数量 | 该日首次发布、并且仍在当前公开集合中的文章数 |
| 本年发布 | 选中年份内首次发布、目前仍公开的文章总数 |
| 发文天数 | 选中年份内至少发布一篇公开文章的日期数 |
| 日期归属 | 按博客配置的统一时区计算 |
| 修改文章 | 不增加首次发文数量 |
| 重复构建与部署 | 不重复计数 |
| 撤回文章 | 从当前公开统计和日期文章列表中移除 |
| 再次公开 | 沿用原首次发布日期，不另记一篇新文章 |
| 草稿和测试文章 | 不进入公开统计 |

统计基于当前发布快照，正式数据更新随站点发布发生。统计口径与截止日期保留在数据和文档中，不作为页面旁注。

本版不提供「草稿写作」「修改次数」切换，也不使用 Git commit 数量替代博客数据。当前文章的创建时间与最后更新时间不能还原每天写过哪些内容；真实逐日写作活动属于另行采集的数据。

### 年份控制

默认显示当前年份，可选择有公开文章的历史年份。当前年份始终保留，即使该年没有发文。

有多个可选年份时显示年份选择器；只有一个年份时显示普通年份文字，不制作只有一个选项的下拉菜单。切换年份后同步更新统计、网格和日期文章列表。

## 桌面热点图

视觉参考 [GitHub 贡献日历](https://docs.github.com/en/account-and-profile/concepts/contributions-on-your-profile) 的每日网格表达，使用本站的苔绿色系和博客统计文案。

### 网格与颜色

- 每列代表一周，每行代表一个星期位置，从周一到周日排列。
- 年首年尾按完整周对齐，非选中年份的位置留空，不伪装成零记录。
- 顶部标注月份，左侧保留星期标记。
- 1440px 稿件中，日格约 12 × 12px，格间距约 4px，圆角 1—2px。
- 中等桌面可使用约 11px 的日格和 3px 间距，保证完整年份可见。
- 根据年份实际天数和起始星期生成网格，不固定为 365 个格子或强行固定列数。

| 当天首次发布篇数 | 日格颜色 | 数量对应 |
| --- | --- | --- |
| 0 | `#E5E9DD` | 0 篇 |
| 1 | `#C8D4BF` | 1 篇 |
| 2 | `#A2B58E` | 2 篇 |
| 3 | `#7C9468` | 3 篇 |
| 4 及以上 | `#596B50` | 4 篇及以上 |

色阶固定，不能随年份自动重新分级，以便跨年比较。页面不单独展示「少 → 多」、篇数色阶说明或「未来」图例，具体日期和篇数通过悬停、聚焦与选中日期的文章列表表达。避免照搬代码贡献数、commit、contributions 等文字。

未来日期使用纸白背景和浅色虚线轮廓，与已过去的零发文日期区分。未来日期不接受选择，也不显示「没有发文」的提示。

### 默认状态与日期选择

进入页面时，选中所选年份内最近一个有公开文章的日期，在图下显示该日文章。全年没有文章时显示空状态。

- 悬停某一日期，仅显示该日提示，不改变下方已经选中的文章列表。
- 提示文案示例：「2026.10.15 · 发布 2 篇」。
- 点击日期，固定选中格并更新图下文章列表；格子用细轮廓表示选中，不放大网格。
- 点击已过去的零发文日期，图下显示「2026.10.14 · 当天没有公开文章」。
- 选中日期列表显示完整文章标题与栏目名称，点击进入文章。
- 日期变化在原地更新，不打开弹窗或侧滑抽屉，不自动滚动页面。

日期列表每条使用细分隔线，标题允许换行。当天文章较多时，完整向下展开，不在此处增加内部滚动或自动翻页。

### 键盘操作

日历使用一个入口进入网格，通过方向键在日期间移动；移动焦点时显示日期与篇数，回车或空格选中日期。避免让用户通过数百次 Tab 才能走过整张图。

年份、日期列表中的文章和月份按钮都需要可见焦点。文章标题、日期与篇数保留可读取的文字，不能只用颜色表达数量。

## 移动端布局

以 390 × 844px 为主要手机画板，并检查 360 × 800px。手机两侧留白沿用项目的 26px，页面使用单栏自然滚动。

页头仍为「← 返回首页」与小号站名，不增加固定顶栏。页面标题、身份信息、扩展介绍、写作日历、生活里的我、最近在做、公开链接依次排列。

### 月度热点图

视口宽度小于 1024px 时，写作日历使用月度视图，数据口径和年度统计保持一致。手机不将全年网格缩成细小方块，也不要求横向拖动整张年历。

- 每行七列，按周一到周日排列，日格内显示日期数字。
- 月份栏显示「2026年10月」，两侧使用「上个月」「下个月」按钮。
- 390px 视口中，日格约 40—44px；360px 视口中约 36—40px，间距按可用宽度调整。
- 使用与桌面相同的五档色阶。较深色日格搭配可读的浅色日期文字，其他日格使用深灰日期文字。
- 本月首尾的非本月位置留空；未来日期使用独立状态并禁用。
- 当前年份默认进入当前月份；选择历史年份时，进入该年最近一次发文所在月份。
- 当前月份有文章时，默认选中最近一个发文日期；该月无文章时，显示该月空状态。
- 月份按钮不跨年份自动跳转，跨年使用年份控制；不能进入当前日期之后的月份。
- 当前选择年份的「本年发布」「发文天数」不随切换月份变成月度统计。

```text

本年发布 24 篇 · 发文 20 天

                [1]  [2]  [3]  [4]

```

平板可以在居中的较窄容器内展示月历，无需把七列格子拉伸铺满宽屏。宽度不超过 900px 时，身份介绍和下半部分双栏也改为纵向排列。

## 视觉规范

### 配色

优先沿用项目现有令牌，热点图的中间色阶作为新增的同色系补充。

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#FAF8F2` |
| 主要文字 | `#343A34` |
| 主要强调与链接 | `#596B50` |
| 链接悬停 | `#43533D` |
| 辅助文字 | `#6B7268` |
| 更弱的标注 | `#8B9385` |
| 分隔线 | `#D8DCCF` |
| 浅色底与零发文日格 | `#E5E9DD` |

必要的正文说明、日期和数量使用足够清楚的文字颜色，不以极浅颜色承载核心信息。热图选中、聚焦和禁用状态均需有颜色之外的区分。

### 字体与字号

沿用项目现有宋体、黑体字体栈，不新增在线字体请求。标题与叙述性文字使用宋体，日期和控件使用黑体；数字保持清楚、稳定的对齐。

| 元素 | 桌面字号 | 手机字号 |
| --- | --- | --- |
| 页面标题「关于我」 | 42—46px | 32—34px |
| 作者名 | 24—28px | 22—24px |
| 分区标题 | 24—28px | 22—24px |
| 签名 | 18px | 17px |
| 原有简介与扩展介绍 | 17—18px | 17px |
| 文章标题链接 | 16—18px | 16—17px |
| 统计、近况日期、入口链接 | 13—14px | 13—14px |
| 图表辅助标注 | 11—12px | 12px |

叙述正文行高约 1.9—2.0，控件与辅助文字行高约 1.5—1.7。长介绍和长标题通过换行解决，不永久截断，也不整体缩小字号。

### 头像与动效

个人页正文身份区复用 `src/assets/avatar/avatar-head.png`，建议显示在约 72—88px 宽的区域内，完整保留图片比例。文章末尾继续使用现有 `avatar-half.png`。

头像源文件只使用现有固定资源，不重新生成角色，不复制到 Markdown 或新的页面素材目录。稿件制作时可引用这些资源；前端实现继续通过静态导入获得资源哈希。

交互反馈沿用约 160ms 的轻微颜色或透明度变化。热点图直接呈现完整数据，避免逐格点亮、循环闪烁、自动切月、头像漂浮等动画。减少动态效果的系统偏好应得到尊重。

## 稿件样例内容

本节的扩展介绍、个人兴趣、近况、文章标题与统计均为排版样例，不代表作者已经确认的真实资料。制作稿件时可直接用于填充；这些说明只写在设计标注中，不放进页面正文。

### 扩展介绍样例

这里用来存放生活里的片段、偶尔冒出来的想法，以及学习过程中值得记住的东西。把它们写下来，是想让日后回看时，还能想起当时的自己。

有时记录一件小事，有时整理一段笔记，也会留下动手尝试的过程。更新跟着生活的节奏走，希望这些文字能慢慢积成一本愿意反复翻看的手记。

### 生活里的我样例

- 记录日常，留意容易被忽略的小事。
- 动手尝试，在小作品里实现偶尔冒出来的想法。
- 把学到的东西整理成自己的文字，方便以后回看。

### 最近在做样例

| 近况 | 更新时间 |
| --- | --- |
| 整理一篇学习笔记 | 2026.10.15 |
| 给一个小工具补上收尾 | 2026.10.09 |
| 把散落的生活片段收进博客 | 2026.10.01 |

## 必须交付的状态

| 状态 | 页面表现 |
| --- | --- |
| 默认有数据 | 展示一致的统计、日格和最近发文日期列表 |
| 日期悬停与键盘聚焦 | 显示完整日期和篇数，不覆盖关键控件，不移动布局 |
| 日期已选中 | 使用细轮廓表示选中，下方显示对应文章 |
| 零发文日期 | 显示「当天没有公开文章」，保留可继续选择的日历 |
| 当前年份无文章 | 统计为 0，显示「这一年还没有公开文章」 |
| 全站无公开文章 | 个人介绍照常展示，日历显示零记录和「这里还没有公开文章」 |
| 手机当前月份无文章 | 年度统计保留，月历下显示「这个月还没有公开文章」 |
| 未来日期 | 与零发文区分，禁用选择 |
| 月份不可继续切换 | 月份按钮显示禁用状态，保留文字含义 |
| 多年份选择 | 展示选择器展开、选中与聚焦状态 |
| 公开链接未填写 | 整个链接区域隐藏，后续区域自然收拢 |
| 长文案与长标题 | 内容完整换行，区域自然增高 |

无 JavaScript 或打印时，身份介绍、个人信息、统计摘要和普通日期文章列表仍能完整阅读。日历交互不可用时不应让正文或公开文章链接消失。

## UI 稿件交付要求

| 稿件 | 规格与内容 |
| --- | --- |
| 关于我桌面完整页 | 1440px 宽，基于 900px 高视口展示首屏，并给出完整长页 |
| 关于我手机完整页 | 390px 宽，基于 844px 高视口展示首屏，并给出完整长页 |
| 首页入口局部稿 | 桌面与手机各一份，展示头像默认、悬停或聚焦状态，使用当前首页作底稿 |
| 文章署名区局部稿 | 桌面与手机各一份，展示现有半身头像与新增「关于我 →」 |
| 热点图组件稿 | 五档颜色、提示、选中、未来、空状态、多年份选择、手机月历与月份按钮 |
| 响应式检查 | 1366 × 768、1024 × 768、768 × 1024、360 × 800px 下的换行、布局与可点击区域 |

字体、头像、分隔线、链接、日格和按钮均保持可独立编辑。主要文字使用真实文本图层，不将整页或整块个人介绍烘焙成图片。标注使用的字号、行高、间距、颜色、点击区域和状态变化。

不要求个人页在桌面一屏内放完全部内容。首页与目录继续遵循原有页面构图要求，不通过修改旧截图或视觉基线掩盖差异。

## 实现与范围约束

公开个人资料继续从现有 `src/config/profile.json` 扩展，原有身份字段保持单一来源；新增的个人介绍、兴趣、近况与公开链接需要对应的数据校验。热点图与日期文章列表只从当前公开发布集合生成，保留现有发布隔离与旧快照行为。

本次 UI 不增加目录页入口、首页额外文字入口、常驻导航、登录注册、网页后台、在线编辑器、发布面板、深色模式、打卡排名、自动翻页或无限滚动。不新增栏目，不在栏目名称旁补解释性副标题。

现有视觉包是只读参考。正式应用位于项目根目录，后续实现不得在视觉包内开发或改写其构建产物。

## 交付验收

- 进入关于我页面的入口只有首页现有头像与文章末尾「关于我 →」。
- 作者名、签名、原有简介、栏目名称及感叹号逐字正确。
- 页面内容顺序为身份介绍、写作日历、兴趣与近况、可选公开链接。
- 热点图使用首次发布口径，样例的 24 篇、20 天、每日数量与文章列表一致。
- 未来、零记录、悬停、选中和键盘焦点具有可识别的不同表现。
- 手机使用月度视图，保留年度统计，360px 宽时整页不水平溢出。
- 长文案完整换行，正文保持可读字号，点击入口容易操作。
- 暖白、深灰、苔绿和现有字体构成主要视觉，不额外更换品牌方向。
- 演示资料与真实身份文字在设计标注中清楚区分。
