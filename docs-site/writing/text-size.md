# 调整文字字号

## 什么时候用

希望放大一句重点或缩小一句补充说明，同时保留现有段落和标题层级时使用。标准 Markdown 没有行内字号符号；下面的 `++` 与 `--` 是 Sachi 的扩展写法。

## 开始前

打开需要修改的文章。普通 Markdown 与[诗歌模式](/writing/poetry)都支持，无需添加元数据。网站、VS Code 插件和本页博客效果共用解析与字号规则。

## 操作步骤

1. 将同一行中需要调整的文字包在一对标记里，标记紧贴内容。

   ```markdown
   这句是普通正文，++这句放大++，--这句缩小--。
   ```

   不写倍数时，放大到周围字号的 1.2 倍，缩小到 0.85 倍；不增加段落、标题或目录条目。

2. 在结束标记后紧接 `{n}` 指定倍数，可以填写正数或小数。

   ```markdown
   ++放大两倍++{2}
   --缩小两倍--{2}
   ++放大一点++{1.5}
   ```

   `++文字++{n}` 将周围字号乘以 n，`--文字--{n}` 将周围字号除以 n。例如原字号 18px 时，前两种分别显示为 36px 和 9px。嵌套时以所在位置的字号为基准；倍数越大，小字越小，建议先看实际可读性。

3. 加粗、斜体与链接可以放在标记内，也可以包住字号标记。完整源码和实际效果紧接如下：

   <<< @/.vitepress/examples/text-size.md

   <BlogExample example="text-size" />

   代码和公式不解析字号标记，链接地址保持原样。标题符号 `#` 继续表示结构；正文小节标题中的字号标记只改变外观，目录只显示文字。

4. 编辑时用 VS Code 预览检查，或保存后检查网站效果。

   ```sh
   npm run blog -- check <文章>
   npm run blog -- dev --post <文章>
   ```

   检查通过返回 VALID；文章页面呈现相同大小比例。插件无需保存即可刷新，点击放大或缩小后的文字仍定位到原 Markdown 行列。

## 确认结果

只有配对文字改变字号。换行、段落、诗歌居中与文章目录继续沿用原规则。手机、打印和无 JavaScript 阅读也保留字号；未完成的配对与无效倍数不会丢失原文。

## 影响与取消

只修改正在编辑的本地正文；删除一对标记与倍数即可恢复普通字号。公开版本仍需明确发布本篇修订后更新。复制到其他 Markdown 工具时，这些扩展标记可能按原文显示。

## 常见问题

- 标记必须在同一条源文件行内配对，不能跨行或段落；正文自动折行不受影响。
- `{n}` 必须紧接结束标记；n 必须是有限正数，不带空格、单位或科学计数法。`{0}`、`{-2}`、`{2px}` 或写了一半的 `{2` 保留为可见文字，字号采用没有倍数时的默认值。
- 需要显示符号本身：写 `\++文字\++` 或 `\--文字\--`；代码示例可以直接使用反引号。
- `C++`、英文单词里的连续符号、单独的 `---` 分隔线、列表与代码不改变含义。标记紧贴英文单词边界时请留一个空格；中文可以直接紧贴标记。
- `flow` 只收集纯文本段落；包含字号、加粗或链接的段落是富文本边界，会保留普通 DOM 排版。需要环绕的段落保持纯文本，把字号说明另起一段，见[环绕教程](/writing/flow)。
- 本写法用于正文，不解析 YAML 的 title 或 summary。
