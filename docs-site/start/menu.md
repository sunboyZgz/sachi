# 认识交互菜单

## 什么时候用

不想记参数、想按提示完成一项操作时，从主菜单进入。这里说明每种输入的按键、默认值和取消边界。

## 开始前

使用真正的交互终端。重定向输入或 --json 模式不会打开问答。

## 操作步骤

1. 在 sachi 根目录运行 `npm run blog`，或已安装的 `blog`。

   ```sh
   npm run blog
   ```

   在终端选择操作，一次完成后退出。

2. 用 ↑/↓ 选择。前四项是新建、预览、检查、发布，第五项是推送冻结版本；文章信息、[正文空格整理](/writing/format)、[稿件留存与回看](/writing/drafts)、查找 ID、系列管理、作品资料、状态、构建、备份随后，撤回与恢复等低频操作在后面。

3. 单选按 Enter。文章多选先按空格勾选，再按 Enter；默认没有文章被勾选。

4. 输入标题、路径等文本。校验错误时留在当前步骤，修正后再提交。

   ```text
   今天想做什么？ → 新建文章 · new
   选择文章栏目 → 生活旁白
   文章类型     → 普通 Markdown
   文章标题 → 秋天的一杯茶
   ```

   选择和输入都在终端完成，不需要输入菜单中的英文标识。

5. 正文空格整理、构建、发布、推送、撤回、回滚、备份和恢复先提供“只查看计划”。真正执行时选择另一项并核对确认。

6. 一次操作完成后退出。要执行下一项，再运行入口；选择“退出”不执行任何操作。

### 一次实际选择过程

新建文章时，只需走过以下问答：

```text
今天想做什么？ → 新建文章 · new
选择文章栏目   → 生活旁白
文章类型       → 普通 Markdown / 诗歌 Markdown
文章标题       → 秋天的一杯茶
结果           → CREATED，显示 file、id、slug、url、type
```

菜单中的英文是操作标识，不需要输入它。想跳过第一层菜单，直接运行 `npm run blog -- new`；栏目、类型和标题仍会按步骤询问。选择“诗歌 Markdown”会写入 type: poem，无需逐行添加反斜杠与居中标记，见[诗歌教程](/writing/poetry)。已有文章可在“查看或修改文章信息”的字段菜单中切换类型。

记得中文名称却不记得 ID 时，选“查找文章 ID”，输入关键词即可。系列管理中的“查找系列 ID”“新建系列”“按 ID 插入文章”各自完成一项操作，见[查找教程](/writing/find)和[系列教程](/writing/series)。

“准备作品资料”提供逐项录入、填写文件录入、生成模板、查询和重新检查，见[作品教程](/writing/toys)。当前仅登记为待媒体处理，不上传、不进入舞台或公开集合；视频超限策略必须明确填写，不能由 --yes 替代。

发布、构建等操作有两种不同的选择：先用空格**选择内容**，再选择“只查看计划”或“执行”。只看计划后程序退出，不会自动接着问是否上线。需要执行时重新打开该操作，文章和目标要再次核对。

确认问题默认“取消”：只按 Enter 不会执行；明确选择继续后才进入写入或网络阶段。多选没有默认全选，也没有一键把所有草稿公开的快捷键。

## 确认结果

你能分辨选择、输入、多选和确认四种步骤。直接运行 `npm run blog -- new` 等命令也能补齐输入。

## 影响与取消

输入阶段 Ctrl+C 以 CANCELLED、退出码 130 结束。写入或网络执行开始后，中断不能当作从未发生，应按结果核实。

## 常见问题

--yes 只跳过执行确认，不填写标题或全选文章。--json 下必须提供具体命令和必要参数。

- 想返回上一步：当前向导没有通用“上一步”按钮。输入阶段按 Ctrl+C 取消，再重新进入，不要用错误值来跳过校验。
- 找不到某项菜单：↑/↓ 可继续移动到屏幕外的选项；一次只显示部分选项，不代表后面的功能不存在。
- 使用自动化脚本：提供具体命令、必要输入和确认选项，见[参数参考](/reference/commands)；不要向交互菜单批量灌入按键。

## 参数方式

本页步骤旁已给出对应写法与结果说明。完整参数可在[命令索引](/reference/commands)按操作名查看；示例占位符请换成实际值，已安装简短命令时可把 `npm run blog --` 换成 `blog`。
